# МЭШ · Тёмная тема

Аккуратная тёмная тема для [Московской электронной школы](https://school.mos.ru)
(`school.mos.ru`). Перекрашивает интерфейс через токены дизайн-системы Lemma
(`--LM-*`), а не грубыми CSS-фильтрами, поэтому текст остаётся контрастным, а
компоненты — читаемыми.

## Возможности

- Три режима: **Тёмная**, **Системная** (по настройке ОС), **Светлая**.
- Пять акцентных цветов: индиго, синий, фиолетовый, зелёный, розовый.
- **Автокоррекция страниц** — докрашивает устаревшие светлые блоки, которые
  ещё не используют токены.
- **Приглушение изображений** — снижает яркость картинок и видео на тёмном фоне.
- Настройки синхронизируются между вкладками `school.mos.ru`.
- Без сбора данных и без внешних запросов; работает только на `school.mos.ru`.

## Установка

### Из Firefox Add-ons (AMO)

> После публикации: <https://addons.mozilla.org/ru/firefox/addon/mesh-dark/>

Нажмите **«Добавить в Firefox»** и откройте `school.mos.ru`.

### Из GitHub Releases

1. Скачайте подписанный `.xpi` из раздела **Releases**.
2. Откройте `about:addons` → шестерёнка → **«Установить дополнение из файла…»**
   → выберите `.xpi` → подтвердите установку.

### Временно, для разработки

1. `about:debugging#/runtime/this-firefox` → **«Загрузить временное дополнение…»**.
2. Выберите `manifest.json` из папки проекта.
3. Откройте `school.mos.ru`. Временное дополнение сбрасывается при полном
   закрытии Firefox.

## Использование

Нажмите иконку луны на панели Firefox:

- **Режим** — тёмная / системная / светлая.
- **Акцент** — цвет ссылок, кнопок и активных элементов.
- **Автокоррекция страниц** — докраска старых светлых блоков.
- **Приглушать изображения** — меньше «слепит» на тёмном фоне.

## Разработка

```bash
npm ci                  # установка web-ext
npm start               # запуск Firefox dev-профиля на school.mos.ru
npm run lint            # проверка манифеста и кода
npm run build           # dist/mesh-dark-<version>.zip и .xpi
npm run sign            # подпись в AMO (нужны AMO_API_KEY / AMO_API_SECRET)
```

Требуется Node.js ≥ 20 и `python3` (для `build.sh`).

## Как это устроено

МЭШ использует дизайн-систему Lemma со 300+ CSS-переменными вида
`--LM-layer-*`, `--LM-content-*`, `--LM-border-*`, `--LM-icon-*`,
`--LM-theme-*`, `--LM-shadow-*`. Компоненты ссылаются на них через `var(...)`,
а значения заданы на `:root`. Расширение переопределяет значения токенов при
`html[data-mesh-dark="on"]` — поэтому перекрашивается весь интерфейс без
точечных правил.

`content.js` при `document_start` выставляет атрибут темы (из
`browser.storage.local`, с быстрым кэшем в `localStorage` против «мигания»),
следит за DOM (`MutationObserver`) для SPA-навигации и при включённой
автокоррекции перекрашивает устаревшие блоки.
